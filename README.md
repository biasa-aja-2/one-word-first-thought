A program that writes one word to /output/entry.txt: mamihlapinatapai, the Yaghan word for the look shared by two people, each wishing the other would start what both want but neither wants to begin. One word, a whole scene — entered in make.fun's One Word, First Thought bounty, where a judge picks the more interesting word two at a time.

## Run it

```sh
python3 main.py
```
